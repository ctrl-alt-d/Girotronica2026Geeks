01

Creative coding

Programar per expressar-se

Què és el creative coding?

Programar per crear experiències,
no pas productes que serveixen per a alguna cosa.

  • Art visual
  • Disseny
  • Música
  • Entreteniment
L'objectiu no és que funcioni «bé», és que expressi alguna cosa. No hi ha resposta correcta.

Codi que dibuixa

// per a cada punt, 60 cops per segon
angle = soroll(p.x, p.y, temps) * 3
p.x += cos(angle)
p.y += sin(angle)
pinta(p, color(angle))

Mou el ratolí per sobre: els punts fugen.

Demo en viu. Moure el control de «Caos» i ensenyar que canviar UN número canvia tot el dibuix. Demanar a algú que triï el número.

Codi que sona

// una nota = una ona
so = audio.createOscillator()
so.type = 'square'
so.frequency.value = 440
so.start()

Un clic, una nota. «Toca sol» improvisa a l'atzar.

Demo en viu, comprovar el volum abans. Canviar el tipus d'ona perquè se senti la diferència. «Toca sol» = música generativa: l'ordinador improvisa.

02

Clown computing

Programar per fer el pallasso

Cloud o clown?

Cloud computing

Els ordinadors d'algú altre fent coses molt serioses.

Clown computing

El teu ordinador fent el pallasso davant de tothom.

  1. No serveix per a res
  2. Hi participa tothom
  3. Si falla, encara fa més gràcia
Les tres regles del clown computing. La tercera és la important: perdre la por a equivocar-se en públic.

El meu primer clown computing

Fressa

Fent fressa, cal encaixar el quadrat petit dins del gros durant 5 segons seguits.

Juguem-hi ctrl-alt-d.github.io/fressa

El codi (p5.js) github.com/ctrl-alt-d/fressa

Obrir la demo i jugar amb tota la sala. Cal donar permís de micròfon i fer clic per activar l'àudio. Anar pujant la dificultat.

a11yConf

Tecnologia responsable

Si no hi pot jugar tothom, no fa gràcia.

  • No hi veus?Que soni, i que el lector de pantalla ho pugui llegir
  • No hi sents?Que es vegi, que hi hagi text
  • No pots fer servir el ratolí?Que funcioni amb teclat
Missatge clau: l'accessibilitat no és un extra, és pensar en tothom des del principi. Les demos d'aquesta presentació funcionen amb teclat i tenen descripció.
